# PLAYGROUND · מערכת כרטיסים וניהול כניסה

אפליקציית SPA (Vite + React + Tailwind v4 + Supabase), מלאה בעברית עם תמיכת RTL.

**האירוע:** 23.10.26 · 11:00-16:30 · מוסללה רופטופ (Muslala Rooftop) · KIMIDA • HUNA • FREYA • GUYJI

## מסכים

| נתיב | מי נכנס | מה יש שם |
|------|---------|----------|
| `/` | קהל | בחירת כרטיס, פרטי משתתפים, מעבר לפייבוקס |
| `/door` | סדרנים (קוד סדרן) | רשימת מאושרי תשלום בלבד, חיפוש וסימון כניסה |

## הקמה

### 1. Supabase

1. צרו פרויקט חדש ב-[supabase.com](https://supabase.com).
2. פתחו **SQL Editor** והריצו את כל התוכן של [`supabase/schema.sql`](supabase/schema.sql).
   הסקריפט יוצר את הטבלאות, את מדיניות ה-RLS ואת נתוני הזרע (3 סבבי מחיר + קונפיגורציה).
   הוא אידמפוטנטי, ובהרצה חוזרת על פרויקט קיים הוא גם מבצע שתי מיגרציות הרסניות:
   - **מסיר את כרטיס ה"זוגי"** (`price_pair`, `ticket_type = 'pair'`). הזמנה זוגית קיימת
     מומרת ליחיד ושורת המשתתף השנייה שלה נמחקת — `total_amount` המקורי נשמר, אז אם באמת
     היו הזמנות זוגיות כדאי לעבור עליהן ידנית אחרי ההרצה.
   - **מעדכן את שלושת הסבבים למחירים שבטבלה למטה**, כלומר דורס שינויי מחיר ידניים
     שביצעתם ב-Supabase.
3. עדכנו את השורה ב-`events_config` לפי האירוע שלכם:

```sql
update public.events_config set
  event_name    = 'שם האירוע',
  sales_start_at = '2026-10-01 10:00+03',
  sales_end_at   = '2026-10-20 23:59+03',
  paybox_url     = 'https://payboxapp.page.link/...',
  helper_pin     = '1234',
  admin_pin      = '9999';
```

### 2. משתני סביבה

```bash
cp .env.example .env
```

ומלאו מתוך **Project Settings → API**:

```
VITE_SUPABASE_URL=https://xxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJ...
```

### 3. הרצה

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # בנייה לפרודקשן לתיקיית dist/
npm run preview
```

> בפריסה (Netlify / Vercel / Cloudflare Pages) יש להגדיר rewrite של כל הנתיבים ל-`index.html`,
> אחרת `/door` ו-`/admin` יחזירו 404 ברענון.

## מחירים ולוגיקה

| סבב | קיבולת | כרטיס יחיד | כרטיס קבוצתי (4) |
|------|--------|------------|-------------------|
| מוקדמות | 40 | 80 ₪ | 280 ₪ (70 ₪ לאדם) |
| כרטיס רגיל | 80 | 90 ₪ | 320 ₪ (80 ₪ לאדם) |
| רגע אחרון | 40 | 100 ₪ | — לא נמכר |

יש שני סוגי כרטיס בלבד: `single` (1) ו-`quad` (4). הכרטיס הזוגי הוסר לחלוטין.

**סבב בלי כרטיס קבוצתי:** `tiers.price_quad` הוא `null` — וזה מה שמסמן "הסוג הזה לא נמכר בסבב".
ב-`/` הכרטיס הקבוצתי מוצג מנוטרל עם ההערה "כרטיסים קבוצתיים אזלו לסבב זה", ו-`createOrder`
דוחה ניסיון ליצור הזמנה כזו גם אם היא נשלחה בכל זאת.

הסבבים (`tiers`) מתמלאים לפי `sort_order`. הסבב הפעיל הוא הראשון שהקיבולת המצטברת שלו
עדיין לא נוצלה על ידי הכרטיסים שנמכרו (כל ההזמנות שאינן `cancelled`).

**כלל הקבוצה:** אם קונים כרטיס קבוצתי כשנותרו בסבב פחות מקומות מגודל הקבוצה — כל הכרטיסים
בהזמנה עדיין מקבלים את מחיר הסבב הפעיל. הספירה פשוט "גולשת" קדימה, והקונה הבא כבר מקבל
את הסבב הבא. המחיר נקבע רגע לפני הכתיבה לפי ספירה חיה, כדי ששני קונים במקביל לא יתפסו
את אותו מקום זול מתוך עמוד ישן.

## זרימת התשלום

1. הלקוח שולח טופס → נוצרת `orders` בסטטוס `pending` + שורת `tickets` לכל משתתף.
2. מסך אישור מציג את הסכום ואת הכפתור לפייבוקס, עם ההנחיה לרשום שם מלא בהערת ההעברה.
3. המנהל רואה את ההזמנה ב-`/admin` תחת "ממתינים לאישור", ולוחץ **אשר תשלום**.
4. באותו רגע הכרטיסים מופיעים ב-`/door` (דרך Supabase Realtime) ואפשר לסמן כניסה.

## הערות

- **קודים:** ה-PIN-ים לא נשלחים לדפדפן. הבדיקה נעשית ב-RPC `verify_pin` (SECURITY DEFINER),
  והדפדפן שומר ב-`sessionStorage` רק את העובדה שהשער נפתח. קוד מנהל פותח גם את `/door`.
- **אבטחה:** זו הגנת "קוד משותף", לא אימות משתמשים. מפתח ה-anon מאפשר קריאה וכתיבה לטבלאות
  `orders`/`tickets` (זה מה שמאפשר לרכוש בלי חשבון ולסמן כניסה בלי התחברות). מתאים לאירוע
  פרטי; אם צריך הגנה חזקה יותר — להעביר את הפעולות ל-Edge Functions עם service role.
- **בחירה מאנשי קשר:** `navigator.contacts.select` נתמך בפועל רק ב-Chrome אנדרואיד על HTTPS.
  בכל סביבה אחרת הכפתור פשוט לא מוצג והמנהל מקליד ידנית.
- **CSV:** הייצוא נכתב עם UTF-8 BOM כדי שאקסל יציג עברית נכון.
- **עיצוב:** Neo-Brutalist / Pop-Art. Tailwind v4 מוגדר מ-CSS ולא מקובץ `tailwind.config.js`,
  ולכן כל הטוקנים (`brand-sky`, `brand-lime`, `brand-yellow`, `brand-coral`, `shadow-brutal*`,
  הגופן Rubik) יושבים בבלוק `@theme` שב-[`src/index.css`](src/index.css). העננים והשמש הם
  SVG inline ב-`src/components/ui.jsx` — אין קבצי תמונה ואין בקשות רשת לנכסים.
